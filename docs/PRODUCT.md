# 产品定义

## 1. 产品定位

SSH Client 是一个以 SSH 交互终端为核心的轻量桌面客户端。

它首先解决：

1. 快速管理和找到大量 SSH 主机。
2. 明确、安全地建立 SSH 会话。
3. 在多个会话之间低成本切换。
4. 网络异常时保留上下文并可恢复。
5. 长时间使用时保持低视觉负担。

它不是服务器监控平台、自动化运维平台或远程桌面。

## 2. 第一阶段核心能力

### 连接管理

- 持久化 SSH 连接
- 分组
- 标签
- 收藏
- 搜索
- 状态筛选
- 复制连接
- SSH Config 导入
- 临时快速连接

### SSH 会话

- 多标签
- 连接 / 重连 / 断开
- 会话保留
- 左右二分终端
- 最近关闭
- 基础会话菜单

### 认证

- Password
- Private Key
- SSH Agent

### 网络

- Direct
- Jump Host / ProxyJump
- SOCKS5
- Timeout
- Keepalive
- Auto reconnect

### 终端偏好

- TERM
- Encoding
- Font
- Font size
- Terminal color scheme

## 3. 信息架构

一级导航：

- 连接
- 会话
- 命令片段
- 快速连接
- 外观
- 设置

工作区：

- 左侧窄导航：一级功能
- 左侧资源栏：连接 / 会话 / 命令片段
- 中央：多标签终端
- 右侧抽屉：当前连接与会话详情
- 顶部：Ctrl+K 全局命令面板
- 底部：当前会话技术状态

## 4. 产品边界

第一阶段不进入主工作区：

- SFTP 文件管理
- Port Forwarding Dashboard
- 服务器性能监控
- 云同步
- 团队共享
- 自动化脚本
- AI 运维助手

这些能力未来可以扩展，但不能改变“连接管理 → SSH 会话 → 终端”的核心路径。

## 5. 产品体验原则

### 不误连接

单击主机只选择，双击或 Enter 才连接。

### 不丢上下文

断线、认证失败、重连失败时，不自动销毁标签页和终端输出。

### 错误要可定位

错误必须区分网络、Host Key、认证、Shell 建立等阶段。

### 安全警告不能被弱化

Host Key Changed 必须默认阻断，不允许设计成普通“继续”提示。

### 高频路径短，低频能力收起

顶部主区不堆按钮，低频操作进入菜单或 Ctrl+K。

## 6. 主题

应用主题：

- Midnight Blue：默认
- Graphite
- Daylight

终端配色独立于应用主题，并固定使用兼容配色。这样 ANSI / OSC 查询与实际终端基础色保持一致，应用主题仅影响终端之外的桌面 UI。

## 7. 界面密度

- Comfortable：连接行约 46px
- Compact：连接行约 40px

不提供更极端的超紧凑模式。
